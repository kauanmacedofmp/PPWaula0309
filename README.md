# Tags Utilizadas
center — centraliza o conteúdo. Está obsoleta no HTML moderno; o ideal é usar CSS.
head — contém informações/configurações da página.
title — define o título que aparece na aba do navegador.
meta — define metadados da página, como codificação e viewport.
header — representa o cabeçalho de uma página/seção.
h1 — título principal.
h2 — subtítulo/título de segundo nível.
style — permite colocar CSS dentro do próprio HTML.
div — elemento genérico usado para agrupar conteúdo.
main — representa o conteúdo principal da página.
section — representa uma seção do conteúdo.
p — cria um parágrafo.
strong — dá importância ao texto, normalmente exibindo-o em negrito.
ol — cria uma lista ordenada/numerada.
li — representa um item de uma lista.
table — cria uma tabela.
tr — cria uma linha da tabela.
th — cria uma célula de cabeçalho da tabela.
footer — representa o rodapé.
form — cria um formulário.
a — cria um link.
button — cria um botão.
img — insere uma imagem.
